# Design System Documentation

## Theme Overview

This document outlines the core visual style and thematic choices for our design system.

## Color Palette

Our color palette is designed to be modern and vibrant, ensuring accessibility and brand consistency.

### Mode
The system operates in a **dark** color mode.

### Core Colors
- **Primary Color:** `#974cf5` - This is our brand's most distinctive color, used for key interactive elements like buttons and calls to action.
- **Secondary Color:** `#8967b6` - A supporting color, ideal for less prominent UI elements, chips, and secondary actions.
- **Tertiary Color:** `#8c4900` - An additional accent color for highlights, badges, or decorative touches.
- **Neutral Color:** `#7c7481` - Our base color for backgrounds, surfaces, and non-chromatic elements.

## Typography

Our typography system is built for readability and hierarchy, utilizing a consistent font family across key elements.

### Fonts
All typographic elements, including headlines, body text, and labels, use the **Inter** font family. This choice provides a clean, modern, and highly legible experience across all interfaces.

## Shape and Spacing

These elements define the physical presence and arrangement of UI components.

### Roundedness
UI elements feature a **moderate** level of roundedness (value: 2). This provides a friendly yet professional aesthetic without being overly soft or sharp.

### Spacing
The system employs a **normal** level of whitespace (value: 2). This ensures a balanced layout, offering sufficient breathing room between elements without feeling sparse or overly dense.
